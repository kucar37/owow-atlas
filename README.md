# OWOW Atlas

OWOW Atlas is a web project created for OWOW.  
The goal of this project is to create a clear and easy-to-use animation library where designers, developers, and clients can view UI animations in one central place.

The library focuses on real UI animations, such as form feedback, scrolling effects, hover states, loading states, and small interaction animations.

## Project Goal

At OWOW, animations can be useful in many projects, but they are not always easy to find, preview, or reuse.

This project tries to solve that by creating a central place where animations can be:

- viewed with live previews
- organized into categories
- reused by developers
- understood by designers and clients
- added to OWOW projects more easily

## Main Features

The current idea for OWOW Atlas includes:

- Animation overview page
- Categories for different animation types
- Live animation previews
- Short explanation for each animation
- Code snippet or implementation details
- Simple and clean user interface

## Target Users

This project is made for different users within OWOW:

### Designers

Designers can explore which animations already exist and use them as inspiration for new designs.

### Developers

Developers can quickly find reusable animations and understand how to implement them.

### Clients

Clients can see examples of possible animations without needing to understand the code.
